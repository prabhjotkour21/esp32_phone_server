================================================================
  ESP32-C3 + Phone Server  |  Complete Setup & Testing Guide
================================================================

TERA ESP32 CODE KAISE KAAM KARTA HAI
--------------------------------------
1. Pehli baar power on karo
2. ESP32 ek WiFi hotspot banata hai: "ESP32C3_Auto_AP" (Password: Password123)
3. Is hotspot se connect karo (phone ya PC se)
4. Browser automatically ek page kholta hai (Captive Portal)
5. Wahan 4 cheezein fill karni hain:
      - WiFi SSID        → apna ghar ka WiFi naam
      - WiFi Password    → apna ghar ka WiFi password
      - Target Server IP → phone ka IP address  ← app se copy karo
      - Target Server Port → 3000               ← app se copy karo
6. Save karo → ESP32 ghar ke WiFi se connect ho jata hai
7. Phir har 5 second mein phone ko POST bhejta hai


STEP 1 — Phone App Setup
--------------------------
1. App kholo
2. "WiFi Config" tab par jao (ya Dashboard par Settings icon)
3. Wahan ek purple card dikhega: "ESP32 Captive Portal Values"
   Usme dikhi:
      Target Server IP   → 192.168.x.x   [Copy] button
      Target Server Port → 3000          [Copy] button
4. Ye dono values apne kisi jagah note kar lo (ya clipboard mein copy karo)

5. Dashboard par wapas jao
6. "Start Server" button dabao
7. VS Code terminal mein ye print hoga:
   [12:34:56] 🟢 SERVER  Started — listening on 0.0.0.0:3000
   [12:34:56] 🟢 SERVER  Waiting for ESP32 to connect...


STEP 2 — ESP32 First Time Setup (Captive Portal)
--------------------------------------------------
1. ESP32 ko power do (USB ya battery)
2. Serial Monitor kholo (115200 baud) — ye print hoga:
      --- Starting ESP32-C3 with WiFiManager ---

3. APNE PHONE/PC KA WiFi change karo:
   Settings → WiFi → "ESP32C3_Auto_AP" se connect karo
   Password: Password123

4. Browser kholo → 192.168.4.1 type karo
   (ya automatic captive portal page khul jayega)

5. Form mein fill karo:
      WiFi SSID          → MyHomeNetwork   (apna actual WiFi naam)
      WiFi Password      → mypassword123   (apna actual WiFi password)
      Target Server IP   → 192.168.1.105   (app se copy kiya hua IP)
      Target Server Port → 3000            (app se copy kiya hua port)

6. "Save" dabao

7. ESP32 Serial Monitor mein ye dikhega:
      Successfully Connected to Wi-Fi!
      --- Configured Server Details ---
      Target Server IP: 192.168.1.105
      Target Server Port: 3000
      ---------------------------------

8. APNA WiFi wapas connect karo ghar ke network par

----------------------------

VS Code terminal mein YE PRINT HONA CHAHIYE:

   [12:35:00] 📡 REQUEST   POST /  ← from 192.168.1.107

   [12:35:05] 📡 REQUEST   POST /  ← from 192.168.1.107
   [12:35:05] ✅ MESSAGE   From 192.168.1.107 → "hello from esp32c3, Count: 1"

ESP32 Serial Monitor mein:
   [5000] Sending: hello from esp32c3, Count: 0

Dashboard par:
   - "ESP32 Connected" card green ho jayega (pulsing dot ke saath)
   - ESP32 ka IP dikhega
   - Messages log mein messages aane lagenge


TERMINAL MEIN KYA DIKHTA HAI — MATLAB
----------------------------------------
   🟢 SERVER    = Server start/stop hua
   📶 NETWORK   = Phone ka IP detect hua
   📍 ESP32 IP  = Pehli baar ESP32 ne connect kiya ← IMPORTANT
   📡 REQUEST   = Har incoming connection
   ✅ MESSAGE   = Message successfully receive hua
   ↩️  REPLY     = ESP32 ko 200 OK bheja
   ⚠️  UNKNOWN  = Galat URL ya method (404)
   ❌ ERROR     = Kuch exception hua


COMMON PROBLEMS
----------------

Problem: ESP32 Serial Monitor mein "HTTP Response: -1"
Fix 1:   Phone ka IP change ho gaya hoga
         → WiFi Config tab mein updated IP dekho
         → Reset button (GPIO 0) dabao ESP32 par 1-2 second
         → Portal dubara fill karo naye IP ke saath

Fix 2:   Server band ho gaya hoga
         → Dashboard par "Start Server" dubara dabao

Fix 3:   Phone aur ESP32 alag WiFi par hain
         → Dono ek hi ghar ke WiFi par hone chahiye

----

Problem: Captive Portal nahi khul raha
Fix:     Browser mein manually type karo: 192.168.4.1
         (Chrome mein http://192.168.4.1 — https mat likhna)

----

Problem: ESP32 WiFi se connect nahi ho raha
Fix:     Serial Monitor dekho — kya dots print ho rahe hain?
         "Connecting to WiFi......." agar bahut zyada time le raha
         hai to SSID ya Password galat hai
         → Reset karo aur portal dubara fill karo

----

Problem: Terminal mein kuch print nahi ho raha
Fix:     - "Start Server" dabao pehle
         - Phone aur ESP32 ek hi WiFi par hain?
         - Phone ka IP sahi daala tha captive portal mein?

----

Problem: ESP32 RESET karna hai (naye IP ke liye)
Fix:     GPIO 0 button (Boot button) ko 1-2 second dabao
         Serial Monitor mein ye dikhega:
         !!! Reset button pressed !!!
         Erasing Wi-Fi credentials and saved server configuration...
         Erase complete. Restarting ESP32-C3...
         Phir captive portal dubara aayega


QUICK TEST — BINA ESP32 KE (Curl se)
---------------------------------------
PC/Mac terminal mein (phone aur PC ek hi WiFi par hone chahiye):

   curl -X POST http://PHONE_IP:3000/ \
        -H "Content-Type: text/plain" \
        -d "test message"

   PHONE_IP = App Dashboard par dikhne wala IP

VS Code terminal mein dikhega:
   [12:35:10] 📡 REQUEST   POST /  ← from 192.168.1.50
   [12:35:10] ✅ MESSAGE   From 192.168.1.50 → "test message"

Agar ye kaam karta hai = Server theek hai, ESP32 bhi kaam karega
